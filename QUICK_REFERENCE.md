# 📚 NagrikSeva - Quick Reference Guide

## 🎯 What is NagrikSeva?

A mobile app where citizens report local civic problems (potholes, water leaks, garbage, etc.) and help each other solve them directly - no government needed!

---

## ✨ Core Features (10 Main Features)

### 1. 🔐 Authentication
- Register with email/password
- Instant login (no email confirmation)
- Secure JWT tokens
- Profile auto-creation

### 2. 📝 Post Problems
- 8 categories (Road, Water, Electricity, etc.)
- Upload 5 photos
- GPS or manual location search
- Instant posting

### 3. 📰 Live Feed
- Real-time problem updates
- Filter by category/status
- Sort by newest/nearest
- Infinite scroll

### 4. 🔍 Problem Details
- Full problem info
- Photo gallery
- Location map
- Contact poster

### 5. 🤝 Help System
- "I Can Help" button
- Track helping status

## 🎨 8 Problem Categories

1. 🛣️ **Road** - Potholes, cracks, damage
2. 💧 **Water** - Leaks, shortage, quality
3. ⚡ **Electricity** - Outages, broken lights
4. 🗑️ **Garbage** - Waste, cleanliness
5. 🌳 **Parks** - Maintenance, damage
6. 🚦 **Traffic** - Signals, congestion
7. 🏗️ **Infrastructure** - Buildings, facilities
8. 📦 **Other** - Everything else

---

## 🚦 3 Problem Statuses

- 🟡 **Posted** - Waiting for help
- 🔵 **Being Helped** - Someone helping
- 🟢 **Solved** - Completed

---

## 📱 4 Main Screens

1. **Feed** - Browse all problems
2. **Post** - Create new problem
3. **Activity** - Track your problems
4. **Profile** - View stats & settings

---

## 🎯 How It Works (3 Steps)

### For Problem Posters:
1. Post problem with photo & location
2. Wait for someone to help
3. Get notified when solved

### For Helpers:
1. Browse problems in feed
2. Click "I Can Help"
3. Go help & mark as solved
